# 楽しい錠剤づくりゲーム（全工程モード）

製剤づくりの全工程を、流れで体験しながら学べる教育用ゲームです。
予備混合 → 造粒 → 乾燥 → 整粒 → 後末混合 → 滑沢剤混合 → 打錠 → フィルムコーティング → 最終QC まで、1つの品目が工場を流れる過程を追います。

> 暫定公開版です。作り込みはこれから進めます。フィードバック歓迎。

## このゲームで体験できること

- **工程のつながり**：1つのパラメーターを変えると、相方のパラメーターも調整が必要になる。工程同士が密接に連携していることを体感できます。
- **粉のパスポート**：中間品の物性（水分・粒度・流動性・素錠硬度など）が工程を渡って次の工程の結果を決めます。
- **遅れて効く失敗**：序盤の小さなミスが、最終QCで初めて表面化することがあります。原因工程までたどるトレーサビリティ表示つき。
- **共通時計480分**：全工程で時間を奪い合います。生産性と品質のトレードオフも判断材料です。
- **現場のトラブル再現**：スティッキング、キャッピング、バインディング、ピーリング、オレンジピールなど。予兆つきで現れ、原因チェーンで「どこで種がまかれたか」が分かります。
